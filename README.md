# 📊 Interactive Delivery & Satisfaction Dashboard — Olist E-Commerce

## CodeAlpha Data Analytics Internship — Task 3 (Data Visualization)

### 🧩 Problem Statement
Olist's Operations leadership needs an ongoing, self-serve way to monitor 
delivery performance and its impact on customer satisfaction — not a one-time 
static report. This project delivers a live interactive dashboard that answers 
key operational questions on demand.

### 🎯 Objective
Build a business-facing, interactive visualization tool (not static charts) 
that helps leadership track delivery KPIs, identify problem regions/categories, 
and quantify the potential impact of operational improvements.

### 🚀 Live Dashboard
👉 **[View Live Dashboard](YOUR_STREAMLIT_LINK_HERE)**

### 🛠 Tools Used
Python, Pandas, Plotly, Streamlit, Google Colab

### 📌 What the Dashboard Answers
1. Is delivery performance improving or worsening over time?
2. Which regions have the worst delivery times?
3. Which product categories drive dissatisfaction — and is it delivery or product-related?
4. Are higher-value orders associated with higher or lower satisfaction?
5. What's the realistic upside if delivery delay were eliminated?

### 📌 Key Findings
- On-time delivery rate and review scores are strongly linked — improving 
  delivery reliability is the highest-leverage lever for satisfaction
- Delivery time varies sharply by state, pointing to clear regional 
  fulfillment investment priorities
- Simulated elimination of delivery delay projects a measurable increase 
  in average review score
